LabSuite

Программы для зуботехнической лаборатории · Software for a dental laboratory

LabSuite — набор программ, которыми пользуется одна зуботехническая лаборатория для внутренней работы: приём работ от техников, отправка на фрезеровку и печать, склад материалов, учёт перепилов.

Согласование работ. Модуль «Фрезеровка» может отправлять 3D-просмотр работы (HTML-файл exocad) на согласование: файл загружается в папку Google Диска лаборатории, а ссылка приходит в рабочую группу лаборатории в мессенджере MAX. Для этого программа запрашивает у Google доступ только к тем файлам Google Диска, которые она создала сама или которые пользователь сам выбрал в окне Google.

LabSuite is internal software of a single dental laboratory. Its milling module can upload a 3D preview of a dental work (an exocad HTML file) to the laboratory's Google Drive folder and post the link to the laboratory's work chat for approval. It requests access only to Google Drive files it creates or that the user picks.
